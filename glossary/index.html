A. AI Infra Stage

判断 AI 基础设施主线处于哪个阶段，以及对应风险纪律。

回到顶部

Thesis Formation｜主线形成期

市场开始围绕 AI Infra 建立核心叙事，但证据仍分散。

触发
产业新闻、订单线索、资本开支方向开始集中。
风险
叙事先行，基本面证据不足。
纪律
观察和建档，避免把早期线索当成强结论。

Validation｜验证期

财报、订单、价格或宏观数据开始验证主线假设。

触发
关键公司财报、供应链数据、价格强度共同确认。
风险
预期提前交易，事件后容易重定价。
纪律
提高复核强度，维持风险纪律。

Diffusion｜扩散期

主线从单一环节扩散到二阶瓶颈和相关资产。

触发
存储、光互连、电力、液冷、PCB 等链条同步获得关注。
风险
扩散过快会带来拥挤和宽度变差。
纪律
看承接和扩散质量，不追逐短期急涨。

Crowding｜拥挤期

资金集中在少数高弹性资产，价格对好消息高度敏感。

触发
成交额放大、强势资产连续加速、情绪指标升温。
风险
利好兑现、冲高回落、事件后波动放大。
纪律
L 关闭或降级，保留现金，等待复盘。

De-risking｜去风险期

事件前或风险升温时，系统主动降低进攻权限。

触发
高影响事件临近、宏观转弱、组合暴露偏高。
风险
过早去风险会错过后续确认，但纪律优先于冲动。
纪律
不新增高弹性暴露，观察事件落地后的承接与复盘确认。

Re-acceleration｜再加速期

经过复盘后，主线被新证据再次强化。

触发
事件落地后价格承接、业绩继续上修、扩散链条健康。
风险
再加速若缺乏宽度，仍可能变成拥挤。
纪律
确认证据质量，逐步恢复观察权限。

Breakdown Risk｜证伪风险期

关键证据开始挑战主线假设，系统进入重点复核。

触发
财报低于预期、订单弱化、库存风险上升、宏观压制明显。
风险
把普通波动误判为主线证伪，或忽略真正证伪。
纪律
转入 Review Loop，先复核再更新判断。

B. H/R/O/M

前哨决策层：主线、风险、机会、宏观。

回到顶部

H：Hypothesis｜主线假设

回答 AI Infra 主线是否仍成立。

触发
产业、财报和价格证据强化时上调。
纪律
影响核心仓观察和主线复核优先级。

R：Risk｜风险假设

回答当前主要风险来自哪里。

触发
拥挤、宏观、政策、库存或 CapEx 压力升温。
纪律
直接约束 L/P 权限和现金纪律。

O：Opportunity｜机会扩散

回答主线如何向二阶机会和国内突破扩散。

触发
电力、液冷、光互连、存储和国产替代获得证据。
纪律
只提高研究优先级，不自动转成交易指令。

M：Macro｜宏观阀门

回答宏观是否允许风险资产继续扩散。

触发
利率、美元、通胀、就业、流动性发生变化。
纪律
决定系统是否保持克制、关闭 L 或观察 P。

C/D/E. H/R/O 子模块

把主线、风险和机会拆成可复核的子假设。

回到顶部

H1：AI Infra 总主线

AI 基础设施作为全球科技资产的核心主线。

H3：电力 / 数据中心物理瓶颈

算力扩张带来的电力、液冷、UPS、机房与设备瓶颈。

H4：存储 / HBM / DRAM

AI 训练和推理需求驱动的高带宽存储瓶颈。

H5：网络 / 光互连 / CPO

GPU 集群扩张后的网络、光通信和互连瓶颈。

R1：云厂 CapEx / ROI 压力

云厂资本开支、融资、自由现金流和投资回报约束。

R2：库存 / 牛鞭风险

需求预期过热后，库存和订单节奏放大波动。

R3：政策 / 出口管制 / 地缘风险

监管、制裁、出口管制和地缘变化对链条的扰动。

R4：估值 / 盈利兑现风险

价格提前反映乐观预期，而盈利兑现不足。

R5：拥挤风险

资金集中、成交过热和高弹性资产连续加速带来的风险。

O1：AGI / Agent 新增需求

新应用范式带来的增量算力和数据中心需求。

O2：AI Infra 二阶扩散

从 GPU 扩散到电力、液冷、光互连、PCB、材料等瓶颈。

O3：防守资产 / 组合稳定器

在科技高波动时提供组合稳定性的资产或现金纪律。

O4：国内关键技术突破机会

国产存储、先进封装、设备材料等关键突破映射。

storage_validation_rally

active

存储/HBM 逻辑被财报、价格或供需验证后的重定价。

触发
强财报、强指引、供需紧张。
确认
相关资产承接且扩散到设备材料。
证伪
财报后承接弱且库存风险上升。
纪律
提高 H4/O4 复核优先级，仍观察 R5。

ai_infra_selective_repricing

active

AI Infra 内部强弱分化，瓶颈资产强于平台或云厂。

触发
供应链强，CapEx 支出方承压。
确认
SMH 或瓶颈链条强于大盘。
证伪
全链条同步转弱。
纪律
分层观察，不把局部强度外推到全部资产。

post-event_crowding_risk

active

事件落地后，前期高预期资产出现拥挤再评估。

触发
财报或发布会落地后价格波动放大。
确认
利好后承接弱或宽度变差。
证伪
回调后快速恢复且扩散健康。
纪律
L 关闭，等待复盘。

o2_diffusion_rally

active

AI Infra 从主链条扩散到二阶瓶颈。

触发
电力、液冷、光互连、PCB 同步增强。
确认
二阶链条持续承接。
证伪
只有单一题材短线冲高。
纪律
研究优先级上调，继续复核证据。

domestic_breakthrough_rally

active

国内关键技术突破或政策映射驱动的结构性行情。

触发
国产替代、政策、订单或技术验证。
确认
O4 相关证据进入台账。
证伪
只有概念热度，没有订单或业绩线索。
纪律
进入 O4 候选复核。

A-H_divergence

active

A股和港股科技资产对同一主线反应不同。

触发
A股硬科技强，港股权重科技弱，或反向分化。
确认
成交、资金和指数宽度不共振。
证伪
A/H 同步修复并获得资金确认。
纪律
分开判断，不机械迁移结论。

narrow_leadership_rally

active

指数看似稳定，但少数板块贡献主要强度。

触发
领涨集中、下跌家数偏多。
确认
宽度差且成交集中。
证伪
扩散到更多行业和资产。
纪律
不放大风险。

sell_the_news

active

事件本身偏正面，但价格因预期过满而回落。

触发
强事件后价格不再上行。
确认
高开低走、成交放大、强资产回落。
证伪
事件后继续承接并扩散。
纪律
转入 post-event review。

pre-event_de-risking

active

高影响事件前系统主动降低进攻权限。

触发
T-3/T-1 临近，组合暴露偏高。
确认
事件风险影响多个持仓。
证伪
事件影响低且组合暴露低。
纪律
保留现金，L 关闭或降级。

thesis_break_drawdown

active

价格下跌来自主线假设被实质挑战。

触发
需求、订单、财报或政策证据明显转弱。
确认
H/R/O/M 多模块同步恶化。
证伪
仅为估值消化或风格轮动。
纪律
进入 Review Loop，重新校准假设。

capex_pressure_overlay

candidate

云厂资本开支和投资回报压力叠加在 AI Infra 主线之上。

触发
云厂自由现金流、融资和 CapEx 争议升温。
纪律
作为候选模式观察，不直接写入正式 PR Registry。

US_leads_AI_Infra_stage

candidate

美股率先验证 AI Infra 阶段变化，再向其他市场映射。

触发
美股半导体和基础设施链条率先出现证据。
纪律
作为候选跨市场状态观察。

A/H_mapping_pending_confirmation

candidate

全球证据已出现，但 A/H 本地行情、资金和证据尚未确认。

触发
A/H 反应分化或宽度不足。
纪律
作为候选映射状态观察。

G. Event Risk / Portfolio Exposure / L/P

事件、组合暴露和工具权限如何联动。

回到顶部

Event Risk

未来事件可能改变 H/R/O/M、PR 或 L/P 权限的风险。

纪律
事件前不放大风险，事件后复盘。

Event Risk Board

把高影响事件、相关资产、组合暴露和动作纪律放在一起观察的面板。

Portfolio Exposure

组合中与某事件或主题相关的资产暴露。估算口径必须明确标注，不默认视作精确权重。

Event Exposure

单个资产对某个事件的直接、间接、宏观或主题暴露。

L Gate

杠杆工具权限阀门，不是交易建议。

纪律
事件风险高或 R5 拥挤时关闭或降级。

P Gate

保护工具权限阀门，不自动执行，只提供风险观察和模拟权限。

L0 / L1 / L2 / L3

从关闭到逐级开放的杠杆权限等级。当前系统优先使用 L0/L1 作为纪律提示。

P0 / P1 / P2 / P3

从无保护到逐级增强的保护观察等级。当前系统多为 P1 观察。

H. AI Infra Bottleneck Map

把 AI Infra 从单一主线拆成可证据化、可复核、可映射组合暴露的产业瓶颈。

回到顶部
打开 Bottleneck Map

Bottleneck Map｜瓶颈地图

把 AI Infra 拆成 Compute、Memory、Network、Power、Cooling、Packaging、Materials、Data Center 等可复核瓶颈。

纪律
瓶颈状态必须回链 Evidence，而不是只停留在产业叙事。

Compute Bottleneck｜算力瓶颈

GPU、ASIC、AI 加速器和 AI 服务器供给是否仍受需求拉动。

Memory Bottleneck｜存储瓶颈

HBM、DRAM、NAND、企业级 SSD 是否继续成为 AI 训练和推理瓶颈。

Network Bottleneck｜网络互连瓶颈

光模块、CPO、硅光、交换机和高速互连是否限制 GPU 集群扩张。

Power / Cooling Bottleneck｜电力与散热瓶颈

电力接入、电网容量、UPS、液冷、PUE 是否限制数据中心扩张。

Packaging / Materials Bottleneck｜封装与材料瓶颈

先进封装、CoWoS、PCB、高速材料和设备材料是否限制 AI 硬件出货。

Data Center Bottleneck｜数据中心建设瓶颈

建设周期、CapEx、融资、自由现金流和 AI ROI 是否匹配 AI Infra 扩张节奏。

I. Evidence / Review

证据如何进入系统，如何被复核，如何影响简报结论。

回到顶部

Evidence

支撑系统判断的结构化证据，是前哨判断燃料。

Evidence Highlights

简报中精选展示的关键证据，必须标注类型、方向、强度、置信度和状态。

Evidence Strength

证据强度，分 strong / medium / weak。

Confidence

系统对证据可靠性的置信度，分 high / medium / low。

verified

证据已由结构化数据源、官方来源或复核流程确认。

pending_review

证据仍需复核。未经复核的新闻可以进入线索池，但不能直接驱动强结论。

Review Loop

把新闻、事件、证据和系统判断重新检查并校准的流程。

Post-event Review

事件落地后检查是否超预期、是否改变 H/R/O/M、PR 和 L/P 权限。

前哨标准证据对象。新闻、宏观、行情、财报和事件都要先结构化，再支撑判断。
